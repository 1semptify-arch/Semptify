{# Inline document viewer — ports the efile_helper DocViewer to the web. Server renders each PDF page to PNG (GET /api/vault/{id}/preview.png), so the document can be reviewed inside Semptify on any device — including phones that cannot show a PDF inline. Include once per page, then: SemptifyDocViewer.mount(element, { documentId: "...", accessToken?: "..." }) The element is emptied and becomes the viewer. Keyboard: ← → turn pages while the viewer has focus. #}
