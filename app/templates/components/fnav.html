{# Function-nav rail — gated stage navigation, rendered from FunctionGroupContract.stages (list of dicts: id, label, action, requires, skippable, and optional grammar fields subject/verb/object/ next_condition/ui_component). Grammar fields (sentence = step): when a stage carries subject, verb, and object, the rail shows the step-intent sentence — "You upload a document" — so the staged flow reads as one paragraph. Stages without grammar fields render exactly as before. Parameters: stages — contract stages (list of dicts). Required. current — index of the active stage (default 0). form_id — id of the form the forward action submits (default ""). back_href — URL for the Back action (default "" = not rendered). back_label — Back label (default "Back"). module_label — left-edge label, e.g. "Journal entry" (default ""). help_anchor — anchor for "Need more info" (default "#shell-side"). skip_href — URL for Skip; rendered only when the current stage declares skippable (default "" = not rendered). The forward button carries data-fnav-requires so static/js/fnav.js can gate it on the named form fields.
