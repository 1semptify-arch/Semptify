What this page is. An honest list of the help Semptify actually needs, and how to start. Semptify is small — the work is public, the review is human, and nothing is asked of you that a person in crisis would pay for.

What this page is not. There is nothing to join, no sign-up, and no commitment. You do as much or as little as you like, through GitHub, in the open.

Ways to give time

  • Code

    Pick an open issue — the ones tagged good first issue are the gentlest place to start — and open a pull request that links it. The developer kit and setup guide are on the developers page.

  • Review the words

    Read a public page or guide and say what is unclear, wrong, or out of date. Plain-language review is real help — the people reading these pages are often in crisis.

  • Test it

    Use the site, try to break it, and file what broke with the steps that caused it. Bugs found before a tenant hits them matter.

  • Translation — not yet

    Real translations are planned but deferred until they can be done properly. Bilingual reviewers are welcome to watch the repository for when that work opens.

  • Suggest a resource

    Know a legal aid office or tenant group that should be listed? Every outside resource Semptify lists is reviewed and approved by a person first — suggestions go through GitHub or the contact page.

The ground rules

These apply to every contribution, however small — they are the same rules the site itself follows.

  • Plain, calm language. No urgency, no pressure, no selling.
  • No accounts, ads, tracking, or anything that keeps people on the site instead of getting them to real help.
  • A tenant's records stay in their own storage. Features respect that model.
  • No dead ends — every page routes a person toward real help.
  • Honest status only — if it is not built, the page says so.

How to start

One step: open the repository. The contribution guide there covers setup, the ground rules in detail, and what a good first pull request looks like.

If code is not your thing, reviewing pages and testing the tools need nothing installed at all — the feedback form is enough.
