The code

All of Semptify's code is public to read, check, and build on: github.com/1semptify-arch/Semptify.

Developer kit (SDK)

A kit for building tools that work with Semptify's vault, document, and context engine systems lives inside the repository under app/sdk/. It is partly ready — usable, but not yet a packaged release.

Module marketplace

A shared place for community-built modules is a long-term goal, not a shipped feature. The Forge pipeline inside the code does exist — modules are built, tested, and promoted through a documented lifecycle. For now, contributions go through GitHub.

API documentation

Public API documentation is not enabled on semptify.org today — there is no /docs, /redoc, or /openapi.json to browse. The OpenAPI specification is generated by the FastAPI code itself and ships with the repository. Whether to expose it publicly is an open decision.

Contribution Guidelines

Semptify is built with discipline: no band-aids, no workarounds, no hallucinations. Contributors should read AGENTS.md before submitting code.
