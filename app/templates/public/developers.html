The code

All of Semptify's code is public to read, check, and build on: github.com/1semptify-arch/Semptify. To run your own copy, see docs/SELF_HOST.md — open mode, enforced mode, and Docker are all covered.

Developer kit (SDK)

A kit for building tools that work with Semptify's vault, document, and timeline systems lives inside the repository under app/sdk/. It is usable but not yet a packaged release. docs/SDK_GUIDE.md walks through each piece — the module SDK, the vault client, and the least-privilege external-module clients.

API documentation

The public API is documented live: /api/docs (Swagger UI) and /api/redoc, generated from /api/openapi.json. The schema lists only the endpoints anyone can call without connecting storage — endpoints that need a session are intentionally not in it.

Module marketplace

A shared place for community-built modules is a long-term goal, not a shipped feature. The plugin-loading machinery and the Forge lifecycle do exist in the code — modules are built, tested, and promoted through a documented pipeline. For now, contributions go through GitHub.

Contribute

Semptify is built with discipline: no band-aids, no workarounds, no hallucinations. Read CONTRIBUTING.md and AGENTS.md before submitting code — and see Volunteer for the ways to give time, including ones that need no code at all.
