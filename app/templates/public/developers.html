The Module SDK

Semptify ships a Python SDK (app/sdk) that modules use to work with the vault, documents, timeline, and context engine. Vault operations go through the canonical VaultClient — a tenant's files stay in their own cloud storage, and the SDK never holds their credentials beyond the session.

The Forge Pipeline

The Forge is Semptify's module development system. Developers can build, test, and promote modules through a lifecycle pipeline — from draft to tested to live. Modules extend the tenant experience or add tools like the PDF toolkit.

API Documentation

When API docs are enabled, Semptify's API is documented at:

  • /api/docs — FastAPI auto-generated docs (Swagger UI)
  • /api/redoc — ReDoc documentation
  • /api/openapi.json — OpenAPI specification

Contribution Guidelines

Semptify is open source and built with discipline: no band-aids, no workarounds, no hallucinations. Contributors should read AGENTS.md in the repository before submitting code.
