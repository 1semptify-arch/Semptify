Plugin directory — coming soon

We are building a directory of client-side plugins that connect directly to your own cloud storage. Semptify Core never holds your documents; the plugins run on your device and use the same storage connection you already trust.

What to expect

  • Browser extension — capture documents and notes while you browse.
  • Desktop app — organize and review records locally.
  • Local script — for developers and power users who want direct control.

For developers

The plugin interface will be documented at /developers as it becomes available. If you want to build with Semptify, start there.
