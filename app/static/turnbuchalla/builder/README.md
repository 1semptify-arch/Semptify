# TURNBUCHALLA — development environment

**The project:** the *Minnesota Rent Assurance & Deposit Protection Act* —
a landlord-funded, experience-rated insurance pool that pays covered rent
during verified tenant hardship and moves deposit/damage disputes out of
the courts into independent claims review. Paid claim ends the matter —
no subrogation, ever.

**Presented by:** Semptify. **Model name:** Turnbuchalla.
**Founder:** Brad Crowe · brad@semptify.org · [phone removed]

## How this folder works

**Process bible: `SSOT_LIVE.md`** — the single source of truth for how
pieces move content → approving → published. Read that first.

This is the project's live workspace. The source documents live in
`01_Court_Cases/_Drafts_Work_Product/` (dated, frozen — linked via
`SOURCES/`). This folder holds the LIVE versions — the ones that keep
evolving as the project moves.

- `ROADMAP.md` — the phase plan; where we are, what's next.
- `BILL_LIVE.md` — the working bill draft (skeleton → statute text).
- `DECISIONS.md` — every design choice and why, so nothing gets relitigated.
- `TASKS.md` — open work, one line each, newest on top.
- `CONTACTS.md` — who we've pitched, who said what, who's next.
- `SOURCES/` — the frozen research + drafts this builds on (links only).
- `01_CONTENT/` → `02_APPROVING/` → `03_PUBLISHED/` — the release
  pipeline; derivatives flow through, masters stay at root.
- `SHARE/` — the live published window (portal-served; don't move it).
- `NOTES_LIVE.md` — Brad's dictation inbox.

## Ground rules (carry over from the case file)

- Facts before reach. A claim that can't survive a fact-check doesn't ship.
- No sales language. The math is the pitch.
- Sends go through Send Center — Brad clicks.
- Dated docs are frozen; live docs live here.
