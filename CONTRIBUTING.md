# Contributing to Semptify

Thanks for considering it. A few things worth knowing up front:

- This codebase is built primarily through AI coding agents (Devin and others),
  with human review on every change. If you're contributing by hand, that's
  great too — just know the conventions may look agent-shaped in places.
- One task per commit. No self-approval on PRs.
- Please read `AGENTS.md` before touching agent-related tooling.

## Getting started
1. Fork the repo
2. Check open issues, especially ones tagged `good first issue` 
3. Open a PR — link the issue it addresses

## Questions
Open a GitHub Discussion or reach out via semptify.org.
