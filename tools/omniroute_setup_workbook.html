OmniRoute Automated Setup Workbook

Step-by-step, local-only interactive guide to install, configure, and test OmniRoute with a working group of AI providers.

1. Install OmniRoute

Choose the install method that matches your machine. After each command, click Next to continue.

npm install -g omniroute
pnpm add -g omniroute@latest --allow-build=better-sqlite3 --allow-build=@swc/core
git clone https://github.com/diegosouzapw/OmniRoute.git
npm install
PORT=20128 DASHBOARD_PORT=20129 NEXT_PUBLIC_BASE_URL=http://localhost:20129 npm run dev
docker pull diegosouzapw/omniroute:latest
docker run -p 20128:20128 -e PORT=20128 diegosouzapw/omniroute

2. Start the Server

Start OmniRoute. The API and dashboard share port 20128 by default.

omniroute

Dashboard: http://localhost:20128  |  API base: http://localhost:20128/v1

omniroute doctor
omniroute setup
