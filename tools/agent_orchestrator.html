Agent Orchestrator Standalone

No server needed. Runs in your browser using localStorage. Open this file in Windsurf preview or any browser tab.

How to use this Agent Orchestrator

  1. 1. Generate the task queue

    Run the sync script in your terminal. This cannot be triggered from the browser for security reasons.

    python tools/sync_orchestrator.py
  2. 2. Load the latest tasks

    Clears your local queue and loads the freshest embedded/project JSON.

  3. 3. Pick a task

    In the Task Queue below, click Copy to copy the prompt for an AI agent, or View prompt to read it first.

  4. 4. Mark progress

    Use the status dropdown in each row to set in_progress, review, resolved, or rejected. Your queue auto-saves to localStorage.

  5. 5. Create custom tasks (optional)

    Use the Create Task form below to add one-off items the sync script doesn't know about.

  6. 6. Backup or move your queue

    Export JSON saves your current queue. Import JSON loads it on another machine.
