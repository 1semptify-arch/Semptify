How to use this Agent Orchestrator (full pipeline)

Manually changing status in this UI is a fallback. Agents should update their own task's status directly via tools/mark_task_status.py the moment they pick up or finish work — that's what keeps this queue accurate without you tracking it by hand.

  1. Generate fresh tasks from the repo: Run python tools/sync_orchestrator.py (use venv311 — Python 3.11.9 only). It runs three sources and merges them by task id:
    • stub_detector.py → scans repo for real stubs (NotImplementedError, pass, TODO)
    • workbook_bridge.py → reads Semptify_Master_Inventory_LIVE_reviewed.xlsx for stub + duplicate rows
    • _seed_orchestrator_tasks.py → compiles incomplete items from BUILD_STATE.md, ACTIVE_CONTEXT.md, FNG_TODO.md, STUB_AUDIT.md into tools/docs_todos.json
    Output: tools/agent_orchestrator_tasks.json (merged) + embedded JSON in this page and tools/orchestrator_dashboard.html.
  2. Open the page fresh: Reload this tab, or click Start fresh ↺ below to clear local cache and pull the newest embedded tasks. You can also double-click the Agent Orchestrator desktop shortcut to launch this page directly.
  3. Pick a task: Use the Task Queue table below, or open tools/orchestrator_dashboard.html for the overview (status/category/agent breakdowns, filterable table). Click View prompt to read the generated prompt, or Copy to paste it into an agent.
  4. Agent picks up the task: Before starting work, the agent runs:
    python tools/mark_task_status.py <task_id> in_progress --agent <model-name>
  5. Agent finishes the task: The agent runs:
    python tools/mark_task_status.py <task_id> resolved --notes "<one-line summary>" --agent <model-name>
    (use review instead of resolved if blocked or unsure, and say why in --notes)
  6. Clear out finished duplicate-resolve tasks: Resolved/rejected tasks stay visible (correctly marked) until someone runs the archive step — they don't disappear on their own, because the underlying workbook row is still there until archived. Periodically run:
    python tools/archive_resolved_duplicates.py --dry-run to preview, then without --dry-run to actually move the rows into the workbook's Archive sheet and drop them from the active queue.
  7. Export/import: Use the Data card below to back up your queue as JSON or move it between machines.
  8. Admin UI (alternative): http://localhost:8000/admin/agent_orchestrator.html (requires stealth admin login). Uses in-memory API store — wipes on server restart. Click Import JSON there to load tools/agent_orchestrator_tasks.json via /api/agent-orchestrator/batch.
  9. Full manual: docs/AGENT_ORCHESTRATOR_MANUAL.md — complete operation guide, troubleshooting, changelog.

Full refresh, in order (run from the repo root with venv311 active):

  1. python tools/sync_orchestrator.py — rebuild stubs + workbook + docs_todos, merge, embed into both HTML views
  2. python tools/archive_resolved_duplicates.py --dry-run — check if anything's ready to clear
  3. python tools/archive_resolved_duplicates.py — clear it if the preview looked right
  4. python tools/sync_orchestrator.py — re-run once more so the HTML views reflect the archive
  5. Reload this page and tools/orchestrator_dashboard.html
