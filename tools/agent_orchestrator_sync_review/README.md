# Agent Orchestrator Sync — Review Package

## Problem

We need three files to stay in sync:

1. `Semptify_Master_Inventory_LIVE_reviewed.xlsx` — workbook with a `Stubs & TODOs` sheet and a `Duplicates` sheet.
2. `tools/stub_tasks_new.json` — generated by `tools/stub_detector.py` scanning the Python code.
3. `tools/agent_orchestrator_tasks.json` — consumed by `tools/agent_orchestrator.html`.

The workbook originally had 155 stale stubs while `stub_tasks_new.json` had 4. Paths in `agent_orchestrator_tasks.json` were missing `app/modules/` prefixes. The `agent_orchestrator.html` UI required manual JSON import and export. The repo root also had an empty stale `stub_tasks.json`.

## Current Solution

- Fixed `tools/workbook_bridge.py` to read `tools/stub_tasks_new.json` as the live stub source.
- `workbook_bridge.py` writes the live stubs back to the workbook's `Stubs & TODOs` tab using `openpyxl`, then reads the `Stubs & TODOs` and `Duplicates` sheets to generate `tools/agent_orchestrator_tasks.json`.
- Deleted `stub_tasks.json` from the repo root.
- Created `tools/sync_orchestrator.py` to run the full pipeline with one command.
- Created `tools/hooks/pre-commit` to run `sync_orchestrator.py` on every commit.
- Set `git config core.hooksPath tools/hooks`.
- Updated `tools/agent_orchestrator.html` to auto-load `agent_orchestrator_tasks.json` on startup when localStorage is empty.

## Current Verified State

- `stub_tasks_new.json`: 0 stubs (the 4 remaining are marked `# stub-detector: ignore`)
- `agent_orchestrator_tasks.json`: 16 tasks, 0 missing paths
- `Semptify_Master_Inventory_LIVE_reviewed.xlsx`: `Stubs & TODOs` cleared, `Duplicates` intact
- `stub_tasks.json` at repo root: removed
