How to use this page

This admin UI stores tasks in server memory (via /api/agent-orchestrator/*). Tasks wipe on server restart. For persistence across restarts, use the standalone UI at tools/agent_orchestrator.html (double-click the desktop shortcut) or see docs/AGENT_ORCHESTRATOR_MANUAL.md.

  1. Generate tasks: Run python tools/sync_orchestrator.py (venv311 / Python 3.11.9). Three sources merge: stubs, workbook, doc-sourced TODOs.
  2. Load them here: Click Import JSON in the Data card below, select tools/agent_orchestrator_tasks.json. Tasks POST to /api/agent-orchestrator/batch.
  3. Dispatch: Click Copy prompt on a task row, paste into a new Windsurf session with the assigned model.
  4. Update status: Use the dropdown on each row, or have agents run python tools/mark_task_status.py <id> <status> --agent <model> directly.
  5. Export: Click Export JSON to back up the current queue before restarting the server.
