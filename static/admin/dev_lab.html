Semptify Forge

Canonical Dev System

Module incubator & lifecycle system. Build, test, and promote modules from dev_only → stable. Admin only.

The Forge is the canonical module development system for Semptify. All new modules start as dev_only (admin-visible only) and progress through the lifecycle pipeline. Only admins see Forge modules; production users see stable and beta only. Promotions persist in PostgreSQL via runtime overrides.
Lifecycle Pipeline: dev_only → preview → experimental → beta → stable
