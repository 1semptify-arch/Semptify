# User Constraints

- User is on limited free tokens; keep responses efficient and minimal.
- This is their first app (Semptify); earlier rework was caused by AI not reading mandatory docs.
- The fixes that stopped rework: SSOT, BUILD_GUIDE, BIBLE, `/ship` workflow, `/cloudflare-dev-mode` workflow.
- Cloudflare caching caused stale app views — use the dev mode workflow.
- User hunts and pecks with one finger; typing is slow and costly.
- Admin dashboard has "Fix It" buttons that send errors to AI; a known issue is that the AI target cannot be chosen.

## Working style

- Be terse and direct.
- Do the work in one pass when possible.
- Do not ask unnecessary questions.
- Show progress with minimal tool calls.
- Prioritize fixes that prevent rework.
