# Journal / Calendar / Timeline

## Journal = Input vessel

- Personal narrative attached to a document/event/personal statement.
- An entry into the record — personal notes.
- It's the **CAPTURE** mechanism, not a viewer.

## Calendar = Total recollection viewer

- Graphical/media view of **EVERYTHING** that transpired in the tenancy.
- Includes appointments, ledger entries, court dates, calls/texts/voicemails/mail/email, all contact interactions, journal entries, events, items.
- Time frames: yearly → 12 months → weekly → days → AM/PM → hourly, all listed by date and time.
- It's the **COMPREHENSIVE VIEWER** of everything.

## Timeline = Interactive data query viewer

- Vertical on mobile, horizontal on desktop.
- Color-coded key definitions.
- Search/filter by names, event type, letters, notices, ledgers, correlations, file types.
- Compare two datasets and adjust query parameters.
- Simplistic database query tool.
