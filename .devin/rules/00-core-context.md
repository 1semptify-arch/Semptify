# Semptify Core Context

The canonical source for the full core context is `CORE_CONTEXT.md` in the repo root. **Read it completely** at the start of every session before writing or approving any code or copy.

## Key non-negotiables (summary)

- Semptify is a **public utility, not a product**.
- North star metric: **Time to Real Help**. Not sessions, return visits, engagement, or signups.
- **No accounts, no sign-up, no email capture, no pop-ups, no ads, no analytics that track individuals.**
- **Never use "free"** to describe Semptify itself. Factual descriptions of outside resources (e.g., "Free legal help for low-income tenants" for Legal Aid) are permitted.
- **There must never be a dead end.** Every error page and broken flow must route the user toward real help.
- Build for stressed, mobile, low-literacy users: one decision at a time, plain language, error state first.
- Before writing code, answer the five questions in `CORE_CONTEXT.md`.
