# Recommended Models for LG Stylo 4 (2GB RAM)

## No-Root (Package 1) — must fit in ~500 MB RAM after Android overhead

| Model | File size (Q4_K_M) | RAM at runtime | Verdict |
|-------|--------------------|----------------|---------|
| Qwen2-0.5B-Instruct   | ~400 MB | ~600 MB | ✅ Best fit, recommended default |
| TinyLlama-1.1B-Chat   | ~670 MB | ~900 MB | ⚠️ Borderline, may get OOM-killed |
| Llama-3.2-1B-Instruct | ~660 MB | ~900 MB | ⚠️ Borderline |

## Rooted (Package 2) — ~1.5 GB available for AI

| Model | File size (Q4_K_M) | RAM at runtime | Verdict |
|-------|--------------------|----------------|---------|
| Qwen2-0.5B-Instruct   | ~400 MB | ~600 MB | ✅ Fast, plenty of headroom |
| TinyLlama-1.1B-Chat   | ~670 MB | ~900 MB | ✅ Good balance |
| Llama-3.2-1B-Instruct | ~660 MB | ~900 MB | ✅ Good balance |
| Phi-1.5-1.3B          | ~790 MB | ~1.0 GB | ✅ Best quality at this size |
| Qwen2-1.5B-Instruct   | ~990 MB | ~1.3 GB | ⚠️ Tight, reduce context to 1024 |

## Unlockable Hardware (Package 3) — 4–8 GB RAM

| Model | File size (Q4_K_M) | RAM at runtime | Verdict |
|-------|--------------------|----------------|---------|
| Qwen2-1.5B-Instruct   | ~990 MB | ~1.3 GB | ✅ Fast |
| Llama-3.2-3B-Instruct | ~2.0 GB | ~2.5 GB | ✅ Recommended on 6GB+ phones |
| Phi-3.5-mini-3.8B     | ~2.5 GB | ~3.0 GB | ✅ Best quality on 8GB phones |
| Qwen2-7B-Instruct     | ~4.4 GB | ~5.5 GB | ⚠️ Only on 8GB+ phones, slow |

## Download URLs

Run these from inside Termux (`wget -O <filename> <url>`):

```bash
# Qwen2-0.5B (default for package 1 and 2)
wget -O models/qwen2-0.5b-instruct-q4_k_m.gguf \
  https://huggingface.co/Qwen/Qwen2-0.5B-Instruct-GGUF/resolve/main/qwen2-0_5b-instruct-q4_k_m.gguf

# TinyLlama-1.1B
wget -O models/tinyllama-1.1b-chat-q4_k_m.gguf \
  https://huggingface.co/TheBloke/TinyLlama-1.1B-Chat-v1.0-GGUF/resolve/main/tinyllama-1.1b-chat-v1.0.Q4_K_M.gguf

# Llama-3.2-1B
wget -O models/llama-3.2-1b-instruct-q4_k_m.gguf \
  https://huggingface.co/lmstudio-community/Llama-3.2-1B-Instruct-GGUF/resolve/main/Llama-3.2-1B-Instruct-Q4_K_M.gguf

# Phi-1.5
wget -O models/phi-1.5-q4_k_m.gguf \
  https://huggingface.co/lmstudio-community/Phi-1.5-1.3B-Instruct-GGUF/resolve/main/Phi-1.5-1.3B-Instruct-Q4_K_M.gguf
```

## Quantization Notes

- **Q4_K_M** is the recommended default — best quality/size tradeoff.
- **Q5_K_M** is slightly better quality, ~25% larger.
- **Q3_K_S** is smaller, noticeably worse quality, only use if RAM-starved.
- **Q8_0** is near-lossless, but 2x larger — only for package 3 hardware.

## Switching Models

```bash
# Stop the server
bash stop_ai_server.sh

# Set the model path and restart
export AI_MODEL="$HOME/ai_host/models/tinyllama-1.1b-chat-q4_k_m.gguf"
bash start_ai_server.sh
```
